## なぜ作ったか

2026年2月、日本で緊急避妊薬が処方箋なしで購入できるようになりました。しかし公式の多言語対応は日本語・英語・中国語が中心です。

在留外国人は約396万人。国籍別2位はベトナム（約63万人）で、ネパールからの在留者も急増しています。**しかし、これらの言語での公式情報は見当たりません。**

緊急避妊薬には**72時間**という時間制限があります。情報にアクセスできないことが、そのまま望まない妊娠につながります。

この空白を埋めるために作りました。

## 特徴

- **72時間カウントダウン** — 性交日時を入力すると残り時間と、その時点での有効率の目安を表示
- **3つの入手経路** — 産婦人科・薬局・オンライン診療を、費用と向き不向きとともに比較
- **言語別URL** — `#vi` `#ne` `#ko` などを付けると、その言語で開くリンクを共有できます
- **ブラウザ言語の自動判定**
- **退避ボタン** — 履歴を残さず別サイトへ移動（見られたくない状況を想定）

## プライバシー設計

緊急避妊薬を調べたという事実は、極めて機密性の高い情報です。

- **外部への通信ゼロ** — Webフォント、アイコン、CDN、アクセス解析を一切読み込みません
- **入力データを送信しません** — 日時の計算は端末内だけで完結します

- **Cookie・トラッキングなし**
